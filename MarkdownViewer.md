**Установить расширение Markdown Viewer**

- Включить доступ к локальным файлам в настройках расширения Chrome.
  1. Скопируйте и вставьте в адресную строку Chrome эту ссылку: chrome://extensions/ и нажмите Enter.
  2. Найдите в списке ваше расширение Markdown Viewer.
  3. Нажмите на кнопку Сведения (Details) внутри карточки расширения.
  4. Прокрутите страницу вниз и найдите пункт Разрешить открывать локальные файлы (Allow access to file URLs).
- Включить поддержку MathJax для отображения формул и Mermaid для диаграмм.
  1. Нажмите на иконку расширения Markdown Viewer на панели инструментов Chrome (справа от адресной строки). Если иконки нет, нажмите на значок «пазла» 🧩 (Расширения) и выберите Markdown Viewer.
  2. В появившемся меню нажмите на значок шестеренки (Settings / Настройки). Откроется вкладка с параметрами расширения.
  3. В левом боковом меню перейдите в раздел Compiler (Компилятор) или Options (Опции).
  4. Найдите и активируйте (поставьте галочки/включите тумблеры) для следующих пунктов: 
     - MathJax (или LaTeX) — для корректного рендеринга формул.
     - Mermaid — для поддержки графиков и диаграмм.
     - Syntax — для подсветки синтаксиса.
  5. Нажмите кнопку Save (Сохранить), если она есть внизу страницы.
